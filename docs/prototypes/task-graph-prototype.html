問題：背景研究、合成與拆除同時進行時，16 個微任務與 7 個背景里程碑應如何推進？所有狀態只存在記憶體。

排程模式

紫框是目前可做的節點，綠框是已完成。圖的依賴邊只控制排程解鎖，遊戲事件判定器仍會阻止不可能提前發生的事件。中文名稱只供人閱讀，模型只收 active task 的 one-hot／embedding。

引導案例

  1. 按「開始拆除登陸艙」。任務圖模式立即推進，不等待拆除動畫。
  2. 拆除進行時只能先按「排入五項科技」。完成後顯示 wait_for_progress，早期製作、燃料和採銅仍被鎖住。
  3. 觸發背景事件「登陸艙拆除完成」。取得初始物資後，早期製作、燃料和採銅才進入 frontier。
  4. 按「排入早期手工製作」、「補充機甲燃料」與「取得前期銅礦」，再觸發「電磁學完成」。
  1. 在基礎物流完成前，放置三台熔爐並手動送料。
  2. 觸發「基礎物流完成」，自動熔煉節點才進入 frontier。
  3. 連接採礦機、傳送帶、分揀器與熔爐後，再進入製造支線。
  1. 讓目前 prompt 停在一個行動節點。
  2. 觸發另一個背景完成事件。
  3. 觀察右側紀錄：里程碑一定鎖定；是否同時發 task reward，正是需要決定的地方。

原型採已確認方案：同一狀態快照成立的事件同時鎖定，且後續狀態逆轉不撤銷。只有 active task 對應的分量成為當下 scalar policy reward。新解鎖任務不會搶佔未完成的 active task。
