# B 建築模式控制追加為第 21 維

2026-09-16，使用者確認 B 為建築模式切換，X 為拆除模式切換。第二批兩回合皆成功，但舊控制清單沒有 B，編譯器因而把其後資料排除。這是動作範圍缺漏，不能要求玩家停用正常的建築操作。

新增 `action_catalog_v4`，B 追加在 index 20，硬體 scan code=0x30；原 index 0–19 保持不變，X 仍為 13。錄製、模型動作、注入、釋放與校正使用同一完整清單。採礦優先排程、遊戲成功條件、未知鍵排除與互斥規則不變，沒有把 B 轉成高階建造巨集。

這修訂 #18／#20 的 v3／20 維契約。原始 evidence v2／v3 可驗證並從實際輸入重新編譯為新 artifact；保留來源 catalog、舊資料與失效紀錄，不就地把 invalid 改成 valid。舊 dataset 與 checkpoint 拒絕以新契約載入。新增控制與 DLL 指紋必須完成新版實機校正，舊核准不可直接沿用。

新增 evaluation-v2，保留 evaluation-v1 及全部綁定檔案。評分門檻、split、抽樣與 40 個保留試驗不變，未查看模型結果。試驗 manifests 與現場輸入設定 hash 的既有差異仍須在正式試驗前處理。舊標註保留原身分，沿用前須核對來源與像素。
