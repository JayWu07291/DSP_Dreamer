## 資料範圍

新版衍生資料位於 `runs/schedule-v4`，來源包括 #18 完整流程、#21 五次／六次流程，以及 `c79d2c8e-e3ff-4f17-94bd-f0ce98a0f3c7.dataset`，皆使用 v3 完成判定。另有三份 v1／v2 資料原樣保留，因產線 predicate 不相容而未混入新索引。新舊數字須連同來源集合比較，不能把減少來源造成的缺口變化歸因於排程。

`rescheduled_from` 保存舊 dataset 身分與 COMPLETED hash。原事件中的 v3 排程宣告仍是原始證據；新版 task 與 scalar reward 是依相同節點事實產生的衍生標籤。沒有修改原始錄製、動作、回合有效性或 split，也沒有把無效回合轉為有效。
