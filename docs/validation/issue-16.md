## 使用者修訂與目前判定

本次對話使用者明確指定：「只驗證產線連接與持續生產」、「不關心是否混入人為放入的材料，只關心最後是不是能建立可自行運作的產線」。此修訂取代本票早期將人工研究站送料一律排除的解讀。人工剩料、補料、先接線再選配方均可接受，不要求清空庫存。

保留固定 16 個微任務、等待 task 16、七個背景里程碑與排程。四項研究供料仍核對全部剩餘需求已進暫存，五項科技仍取真正解鎖事件；供料 reward 鎖定後不撤回。三台不同固定配方熔爐仍須先在無自動輸入下各完成人工熔煉。

新版保存機器目前的供電、上游來源、輸送帶路徑及實際批次。沿傳送帶方向反查，考慮分揀器方向、篩選與供電；採礦機須有對應礦脈、供電與傳送帶。製造台兩種原料都須連到已在自動連接下完成批次的固定配方熔爐；研究站同理須連到兩條已實際生產的製造支線。

批次開始與完成時都核對目前整條上游連接。`setup_lab` 代表兩支線已連通，`matrix_done` 還需要研究站真正完成批次。只建空殼、缺電、缺任一原料支線、途中斷線、僅人工餵料而沒有完整上游、單機反覆改配方都不能替代完整產線。手動補料本身不失去資格，也不宣稱辨識每一顆物料的來源。建造中可更正配方；更正會清除該機先前的生產證據，最後仍需同時存在各自配方的完整支線。

錄製器移除不再需要的 cargo 來源追蹤；輸送帶延伸時遊戲重建 cargo ID 不影響連接判定。舊版 1、2 的 compiler 重播語意保留，舊錄製不改標、不覆寫，也不能憑舊資料缺少的連接快照宣稱 v3 成功。
