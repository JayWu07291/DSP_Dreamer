## 判定

保留 #12 的固定 16 個微任務、等待 task 16 與七個背景里程碑。新版來源保存 `progress_version=2`；舊版 1 保持原有早期 predicate，不從新增規則推測舊錄製的後期完成。

產線記錄配方、原生輸入庫存、正常批次消耗及完成。三台不同實體的熔爐須各自維持鐵塊、磁鐵、銅塊配方。人工熔煉要求開始批次與產出時皆無輸入分揀器。改配方的同一台機器不能再當另一條固定配方支線；拆除會清除其尚未合計完成的支線證據，已鎖定節點保持不變。

採礦機產物沿遊戲 cargo ID 經傳送帶與分揀器移動。直接從採礦機送入分揀器不能滿足傳送帶要求。製造台可經分揀器直接取得合格熔煉產物，也可透過傳送帶；研究站必須取得兩種合格製造產物。來源追蹤保留實際數量，人工放上輸送帶的同種物品沒有合格來源。

物品堆疊沒有逐件來源 ID。混合庫存只保留可證明的來源數量下界，批次開始時必須能證明全部所需輸入。手動取放會清除對該機器輸入的來源保證；手動送料到研究站會讓該研究站失去最終成功資格，重新選相同配方也不解除。可另建新的研究站繼續。

`setup_lab` 在兩支線都曾經分揀器送料時成立。其後合格批次真正產出電磁矩陣才成立 `matrix_done`，並以既有 `EndEpisode("success")` 保留 final observation、終止標籤與控制釋放。只有供料或庫存增加不等於研究站產出。

## 實機驗收步驟

1. 關閉 DSP，使用 `tools/deploy-recorder.ps1` 建置、備份及部署，維持 Diagnostics 關閉。啟動後先按 F8 產生候選指紋，核對並核准新版插件雜湊後，再按 F8 重載 `Starting Save`。
2. 從拆登陸艙開始完成 #15 早期流程，依序排五項科技。自動化冶金先缺一種材料，再補足；可暫停自動研究退回材料，確認供料完成只記一次，科技解鎖仍須實際完成。
3. 建立三台熔爐，分別設定鐵塊、磁鐵、銅塊。先不要接輸入分揀器，人工送料，等各產出至少一個成品。清空人工剩餘輸入與產物後，再接採礦機、傳送帶與分揀器，等三種自動產物。
4. 建立兩台固定配方製造台，分別做磁線圈與電路板。從自動熔煉輸出經分揀器供料，等各完成至少一批。不要把手工製品補入這兩條驗收支線。
5. 電磁矩陣科技完成後建立研究站，固定電磁矩陣配方。先連一條支線，確認仍未完成；再連另一條，確認 `setup_lab` 先於真正產出。最後一次送料後的三秒製作時間可供區分兩者。
6. 首次合格產出後回合應自動成功結束。按 F8 發布。另以 F9 重試或新錄製做人工研究站送料反例，該站即使有矩陣產出也不得成功。
7. 保存來源、遊戲日誌與四檔 evidence，完整解碼、checksum 核對、重新編譯與 loader 讀回。逐回合記錄提示序列、節點時間、reward、final observation、有效性與 gaps，再更新本報告的實機狀態。
